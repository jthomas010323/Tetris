# Tetris Game (Java / JavaFX)

A desktop-based Tetris game developed as a **team project**, focusing on **UI design, animations, and user interaction**. The project demonstrates front-end development skills using Java and JavaFX.

## 🎮 Overview
This project recreates the classic Tetris game with a modern user interface, smooth animations, sound effects, and an interactive main menu. The game runs as a desktop application and emphasizes user experience and visual polish.

## 🛠 Tech Stack
- Java  
- JavaFX  
- Object-Oriented Programming (OOP)

## ✨ Features
- Interactive main menu and game screens  
- Smooth animations and visual effects  
- Background music and sound effects  
- Responsive keyboard controls  
- Clean and organized UI layout

1. Clone the repository

3. Ensure JavaFX is properly configured
4. Run the main application file
